# Catalyst → Entry → Valuation → Return → Holding Period → Thesis Break

## Catalyst Map

A good thesis alone is not investable — there must be a mechanism for the market to notice it.
Analyze via this chain:

```
Leading Indicator → Catalyst Event → Earnings Revision → Market Recognition → Price Re-rating
```

Candidate catalysts: 가격 인상 후 Churn 공개, ARPU 상승, Premium Mix 증가, Margin Beat,
Retention/Cohort 공시, Guidance 상향, Investor Day, 신규 제품, 경쟁사 철수, 시장점유율 상승.

For each catalyst give: 예상 시점 / 관찰해야 할 데이터 / 시장 예상과 다른 결과가 나올 가능성 /
Earnings impact.

Memo table: `| Catalyst | Leading Indicator | 예상 시점 | Earnings Impact |`

## Entry Timing

Never output a bare BUY/WATCH. Always pick exactly one:

- **BUY NOW** — 현재 가격에서 충분한 Upside가 있고 Catalyst가 가까움
- **BUY ON CONFIRMATION** — Thesis는 유효하지만 핵심 데이터 한두 개 확인 필요
- **BUY ON WEAKNESS** — Thesis는 강하지만 Valuation이 높아 가격조정 필요
- **WAIT** — Thesis 또는 Catalyst가 아직 충분하지 않음

Then state explicitly: 어떤 데이터 / 이벤트 / 가격조건이 충족되면 진입할 것인지.

## Valuation

Choose the multiple(s) appropriate to the business (P/E, EV/EBITDA, EV/Sales, EV/FCF, FCF Yield).
Compare: 현재 Multiple / 역사적 Range / Peer Multiple / Bull-Base-Bear 가정.

Where possible, reverse-engineer what the current price implies, e.g.:
> "현재 가격은 향후 3년 Revenue CAGR XX%, Operating Margin XX%를 암묵적으로 요구"

Core question: 우리가 발견한 Retention→Pricing Power 전환이 현재 가격에 이미 반영되어 있는가?

## Expected Return

Decompose where data allows:

- Fundamental Return (EPS/FCF growth)
- Re-rating Return (Multiple expansion)
- Dividend/Buyback
- = Total Expected Return

Present as Bull / Base / Bear scenarios. If data is insufficient, write "Insufficient Data" instead
of fabricating numbers.

Memo table: `| Scenario | Earnings Growth | Multiple | Expected Return |`

## Holding Period

Default 1–2 years, adjusted for catalyst speed and retention/pricing conversion speed. Always state:
- Expected Holding Period
- 첫 번째 Thesis Checkpoint
- 두 번째 Thesis Checkpoint
- 예상 Market Recognition Window

## Thesis Break / Sell Discipline

Price decline alone is never a thesis break. Judge only by damage to the leading indicators that
compose the thesis.

- **Confirmation Signal** — e.g., ASP 상승 + Churn 안정, Premium Mix 상승
- **Weakening Signal** — e.g., Retention 정체, 가격인상 지연
- **Break Signal** — e.g., 가격인상 후 Churn 급증, Retention Curve 구조적 하락
- **Sell Trigger** — Break Signal이 일회성이 아니라 반복 확인되는 경우

Also define separately: Valuation-based Exit, Fundamental-based Exit, Time-based Exit.
