# Pricing Power Test

This is the single most important isolated analysis in the skill. Answer all four tests in order,
with data + period + source for every number. If data is missing, say "Insufficient Data" — do not
infer a positive answer.

### Test 1 — 실제 가격 인상이 있었는가?
- 가격 인상 횟수
- 인상률
- 시점
- 경쟁사 대비 가격 변화

### Test 2 — 가격을 올렸는데 고객이 남았는가?
Compare directly:
- **Price Increase 전 Retention/Churn**
- **Price Increase 후 Retention/Churn**

This before/after comparison is the strongest single piece of evidence the whole memo can produce.
If this data exists, it should anchor the Core Thesis verdict.

### Test 3 — 직접 가격 인상이 아니더라도 Mix를 통해 가격을 올리고 있는가?
Look for: Premium Tier, Upsell, Higher-priced SKU, Add-on, Bundle, 광고 없는 상품(ad-free tier),
멤버십 상위 Tier.

### Test 4 — 경쟁사 대비 Premium을 유지하는가?
Where possible, compute:
- **Company ASP / Peer ASP**

  Premium Mix / Peer Premium)
