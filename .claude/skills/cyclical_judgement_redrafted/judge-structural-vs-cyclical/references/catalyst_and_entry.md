# Catalyst → Entry → Valuation → Return → Holding Period → Thesis Break

## Catalyst Map

좋은 Thesis만으로는 투자 대상이 안 된다 — 시장이 그것을 알아차릴 메커니즘이 있어야 한다.

```
Leading Indicator → Catalyst Event → Earnings Revision → Market Recognition → Price Re-rating
```

후보 촉매: 침투율/코호트 데이터 공개, 경쟁사 구조조정·퇴출(카테고리 축소가 아니라 재편임을
증명), Peer Divergence의 명시적 데이터화, 셀사이드 섹터 재분류 리포트, 관세/정책 불확실성
해소, 신규 지역/세대 성장 데이터 공시.

각 촉매마다: 예상 시점 / 관찰해야 할 데이터 / 시장 예상과 다른 결과가 나올 가능성 /
Earnings Impact.

Memo table: `| Catalyst | Leading Indicator | 예상 시점 | Earnings Impact |`

## Entry Timing

BUY/WATCH만 내지 말고 항상 다음 4개 중 정확히 하나를 고른다:

- **BUY NOW** — 현재 가격에서 충분한 Upside가 있고 Catalyst가 가까움
- **BUY ON CONFIRMATION** — Thesis는 유효하지만 핵심 데이터(침투율, Peer Divergence 등) 한두
  개 확인 필요
- **BUY ON WEAKNESS** — Thesis는 강하지만 Valuation이 이미 높아 가격조정 필요
- **WAIT** — Thesis 또는 Catalyst가 아직 충분하지 않음, 또는 Financial Transmission Chain이
  아직 끊긴 상태

그다음 어떤 데이터/이벤트/가격조건이 충족되면 진입할지 명시적으로 쓴다.

## Valuation

업종에 맞는 Multiple(P/E, EV/EBITDA, EV/Sales 등)을 고른다. 비교: 현재 Multiple / 역사적
Range / Peer Multiple / Bull-Base-Bear 가정.

가능하면 현재 가격이 암묵적으로 요구하는 것을 역산한다, 예:
> "현재 가격은 향후 침투율이 연 X pp씩 상승하며, 카테고리 편승이 아닌 자사 고유 우위가
> 유지된다는 것을 암묵적으로 요구."

핵심 질문: 우리가 발견한 구조적 전환이 현재 가격에 이미 반영되어 있는가(Valuation Gate)?

## Expected Return

가능하면 분해:

- Fundamental Return (EPS/FCF 성장)
- Re-rating Return (Multiple 확장/축소)
- Dividend/Buyback

Bull/Base/Bear 시나리오로 제시. 데이터가 불충분하면 숫자를 지어내지 말고 "Insufficient
Data"라고 쓴다.

Memo table: `| Scenario | 구조/순환 판정 | Multiple 반응 | Expected Return |`

## Holding Period

기본 2~3년(이 철학은 구조 검증에 시간이 걸림), Catalyst 속도에 따라 조정. 항상 명시:
- Expected Holding Period
- 첫 번째 Thesis Checkpoint
- 두 번째 Thesis Checkpoint
- 예상 Market Recognition Window

## Thesis Break / Sell Discipline

주가 하락만으로는 Thesis Break가 아니다. Thesis를 구성하는 선행지표의 손상 여부로만
판단한다.

- **Confirmation Signal** — 예: Peer Divergence 데이터 확인, 침투율 지속 상승, Core Margin
  반등
- **Weakening Signal** — 예: 신규 지역/세대 성장률이 카테고리 평균으로 수렴, Multiple
  재분류 지연
- **Break Signal** — 예: 자사 Comp가 경쟁사 대비 역전, 할인/프로모션 의존도 상승(구조적
  우위가 아니라 카테고리 편승이었다는 증거)
- **Sell Trigger** — Break Signal이 2개 분기 이상 연속 확인되는 경우(보유 시 기준)

Valuation-based Exit, Fundamental-based Exit, Time-based Exit도 별도로 정의한다.
