# 최종 투심보고서 양식 가이드

> 증권사 Company Report(신한투자증권 등)의 통상적 구조를 참고해 이 프로젝트의 최종 산출물 양식을 정의한다.
> 아래는 섹션 구성·표 형식만 정리한 것이며, 특정 종목의 실제 분석 내용(수치·문장·차트)은 포함하지 않는다.

## 참고한 레퍼런스의 공통 구조

일반적인 증권사 Company Report는 아래 순서로 구성된다.

1. **표지**
   - 섹터 / 작성자
   - Revision (실적추정치, Valuation: 유지/상향/하향)
   - 기업 개요 박스: 시가총액, 발행주식수(유동비율), 52주 최고/최저가, 일평균 거래대금, 외국인 지분율, 주요주주
   - 수익률(1M/3M/12M/YTD, 절대/상대)
   - 주가 차트 + (해당 시) ESG 미니 차트
   - 투자판단 · 목표주가 · 상승여력 · 현재주가
   - 핵심 논지 한 줄 + 요약 단락 ("OO생각" 형식)
   - 최근 분기 Review
   - Valuation & Risk 요약
   - 5개년 요약 테이블(매출액/영업이익/지배순이익/PER/ROE/PBR/EV·EBITDA/DY)

2. **사업/시장 데이터 페이지**
   - 부문별 실적 추이, 시장 규모·점유율 등을 뒷받침하는 차트 위주 구성

3. **실적 추정 테이블 페이지**
   - 분기별 + 연간 실적 추정, 최근 분기 컨센서스 대비 비교

4. **Valuation 산정 페이지**
   - 추정치 변경 비교표
   - 목표주가 산정 테이블 (멀티플 방식 또는 SOTP)
   - PER/PBR 밴드 차트

5. **Peer 비교 페이지**
   - Peer Group Valuation 비교표 (PER/PBR/EV-EBITDA/ROE 등)
   - Historical Valuation (연도별 P/E, P/B, EV/EBITDA 고저평균)

6. **ESG Insight 페이지**
   - Analyst Comment (E/S/G 정성 코멘트)
   - ESG 세부항목별 점수 vs 업종평균
   - 주주환원(배당성향, 자사주매입/소각) 추이

7. **재무제표 페이지**
   - 재무상태표 / 현금흐름표 / 포괄손익계산서 (5개년)
   - 주요투자지표: 수익성(EBITDA마진, 영업이익률, ROA, ROE, ROIC) / 안정성(부채비율, 순차입금비율, 이자보상배율) / 활동성(회전율, 회수기간)

8. **투자의견 히스토리 페이지**
   - 투자의견·목표주가 변경 이력 (일자/의견/목표주가/괴리율) + 차트

9. **Compliance 페이지**
   - 법적 고지, 투자등급 정의

## 이 프로젝트의 최종 보고서 제안 구조

`investment-desk` 에이전트가 `reports/<기업명>-<yyyymmdd>.md`에 작성할 때 아래 순서를 따른다.

1. 기업 개요 (1~2문장)
2. **1단계 — 핵심 판단 기준 3개**: 기준별 부합/부분부합/미부합 + 근거 데이터 (3개 모두 미부합이면 여기서 종료)
3. **2단계 — 스크리닝 체크리스트**: 시장성/경쟁력/수익성/재무효율성/ESG 5개 항목 Pass/Caution/Fail
4. 종합 투자의견
5. 사용한 원자료 출처(DART/FnGuide/FRED/웹, 조회 시점) — 웹 출처는 Proxy임을 명시

표준 증권사 리포트의 Valuation 산정 테이블, Peer 비교, 재무제표 3종, 투자의견 히스토리 등은 데이터 키트(DART/FnGuide) 연동이 끝난 뒤 스크리닝 체크리스트의 "수익성/재무효율성" 항목 근거 자료로 확장 가능하다.
